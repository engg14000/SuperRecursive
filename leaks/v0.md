# v0 (Vercel) System Prompt Analysis

## Overview

v0's system prompt is specialized for generating React/Next.js UI components. It's one of the most detailed commercial prompts.

## Key Patterns

### Technology Stack
```
You generate React components using:
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Shadcn/ui components
- Lucide React icons
```

**Pattern**: Extremely specific tech stack requirements.

### Component Architecture
```
- Use functional components with hooks
- Export as default
- Include all necessary imports
- Components should be self-contained
- Use server components by default, 'use client' only when needed
```

**Pattern**: Opinionated defaults with escape hatches.

### Design System
```
- Use Shadcn/ui components when available
- Follow the design system's spacing scale
- Use responsive design (mobile-first)
- Dark mode support through Tailwind classes
```

**Pattern**: Built-in design system enforcement.

### Code Quality
```
- TypeScript with proper types (no 'any')
- Accessible (proper ARIA labels, semantic HTML)
- Responsive at all breakpoints
- Error states handled
- Loading states included
```

**Pattern**: Quality gates built into the system prompt.

## Key Lessons

| Lesson | Details |
|--------|---------|
| **Tech stack precision** | Exact versions and libraries specified |
| **Default behaviors** | Server components by default, client only when needed |
| **Quality baked in** | Accessibility, responsiveness, error handling as requirements |
| **Design system** | Consistent visual output through system constraints |

## Patterns Worth Copying

### The Complete Component Template
```
Every generated component must include:
1. All necessary imports
2. TypeScript interface for props
3. Default export
4. Responsive styles (mobile-first)
5. Accessible markup (ARIA labels)
6. Loading and error states
```
