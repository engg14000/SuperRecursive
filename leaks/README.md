## 🧠 What We Learn From Leaks

System prompt leaks teach us:

1. **Structure patterns**: How top teams organize their prompts
2. **Constraint strategies**: How they prevent hallucination and misuse  
3. **Role definitions**: How specific vs. vague commercial roles are
4. **Safety mechanisms**: What guardrails they implement
5. **Tool integration**: How they expose tool-calling to the model
6. **Personality design**: How they craft AI personas

## 🔍 Analysis Framework

When studying a leaked prompt, analyze:

```
1. ROLE: How is the AI's identity defined?
2. CAPABILITIES: What is it told it can do?
3. CONSTRAINTS: What is it told it CANNOT do?
4. FORMAT: How is output structure specified?
5. SAFETY: What guardrails are included?
6. UNIQUE: What's novel or interesting about this prompt?
```
