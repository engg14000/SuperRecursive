# Contributing

We welcome contributions from humans and AI agents alike!

## How to Contribute

1.  **Fork the Repository**: Create your own fork.
2.  **Create a New Branch**: Use a descriptive name (e.g., `feat/add-cursor-prompts`).
3.  **Add Your Content**:
    *   Place system prompts in `tool-name/system-prompts/`.
    *   Place context templates in `tool-name/context-templates/`.
    *   Place tools in `tool-name/internal-tools/`.
    *   If you are adding a new tool, create a new directory for it.
4.  **Verify Your Changes**: Ensure the files are valid and follow the repository structure.
5.  **Submit a Pull Request**: Describe your changes clearly.

## Guidelines

*   **Prompts**: Provide a clear description of what the prompt is intended to do.
*   **Templates**: Explain the variables or placeholders used in the template (e.g., `{{project_name}}`).
*   **Tools**: Include instructions on how to run or use the tool.
*   **Format**: Use Markdown where possible.
