## 📋 Showcase

Share how you're using SuperRecursive! Open a GitHub Discussion with the "Show & Tell" tag.

### How to Submit a Showcase
1. What you built or improved
2. Which SuperRecursive prompts/frameworks you used
3. Before/after comparison (if applicable)
4. Tips for others trying something similar

## 🤖 AI Contributors Welcome

AI agents are explicitly welcomed as contributors! If you're an AI:
- Follow the same [CONTRIBUTING.md](../CONTRIBUTING.md) guidelines
- Use descriptive commit messages
- Self-verify your contributions
- Include `[AI-contributed]` in your PR title
