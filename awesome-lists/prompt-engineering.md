## Papers

### Foundational
- [Chain-of-Thought Prompting Elicits Reasoning](https://arxiv.org/abs/2201.11903) — The original CoT paper by Google (Wei et al., 2022)
- [Tree of Thoughts](https://arxiv.org/abs/2305.10601) — Deliberate problem solving with LLMs (Yao et al., 2023)
- [ReAct: Synergizing Reasoning and Acting](https://arxiv.org/abs/2210.03629) — Interleaving thought and action (Yao et al., 2023)
- [Self-Refine](https://arxiv.org/abs/2303.17651) — Iterative refinement with self-feedback (Madaan et al., 2023)
- [Reflexion](https://arxiv.org/abs/2303.11366) — Language agents with verbal reinforcement learning (Shinn et al., 2023)

### Advanced
- [LATS: Language Agent Tree Search](https://arxiv.org/abs/2310.04406) — Monte Carlo tree search for LLM agents
- [DSPy](https://arxiv.org/abs/2310.03714) — Programming rather than prompting LMs
- [Prompt Engineering Guide](https://arxiv.org/abs/2302.11382) — Comprehensive survey of prompting techniques
- [Lost in the Middle](https://arxiv.org/abs/2307.03172) — How LLMs use long contexts
- [Constitutional AI](https://arxiv.org/abs/2212.08073) — Training AI with principles

## Tools

### Prompt Development
- [PromptFoo](https://github.com/promptfoo/promptfoo) — Prompt testing and evaluation framework
- [Prompttools](https://github.com/hegelai/prompttools) — Tools for testing and experimenting with prompts
- [Agenta](https://github.com/Agenta-AI/agenta) — LLM app building and management platform
