# Awesome AI Agents [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Curated list of frameworks, papers, and tools for building autonomous AI agents.

## Frameworks

### Multi-Agent
- [CrewAI](https://github.com/joaomdmoura/crewAI) — Framework for orchestrating role-playing AI agents
- [AutoGen](https://github.com/microsoft/autogen) — Multi-agent conversation framework by Microsoft
- [LangGraph](https://github.com/langchain-ai/langgraph) — Building stateful, multi-actor LLM applications
- [Swarm](https://github.com/openai/swarm) — OpenAI's lightweight multi-agent framework
- [MetaGPT](https://github.com/geekan/MetaGPT) — Multi-agent framework simulating a software company

### Single Agent
- [LangChain](https://github.com/langchain-ai/langchain) — Building LLM-powered applications
- [LlamaIndex](https://github.com/run-llama/llama_index) — Data framework for LLM applications
- [Haystack](https://github.com/deepset-ai/haystack) — End-to-end NLP framework for search and agents
- [Semantic Kernel](https://github.com/microsoft/semantic-kernel) — Microsoft's lightweight AI SDK

### Autonomous Coding Agents
- [Devin](https://devin.ai) — Autonomous AI software engineer
- [SWE-Agent](https://github.com/princeton-nlp/SWE-agent) — Solves GitHub issues autonomously
- [OpenDevin](https://github.com/OpenDevin/OpenDevin) — Open-source Devin alternative
- [Aider](https://github.com/paul-gauthier/aider) — AI pair programming in the terminal
- [Mentat](https://github.com/AbanteAI/mentat) — AI coding assistant in the terminal

### Browser Agents
- [Browser Use](https://github.com/browser-use/browser-use) — Make LLMs interact with browsers
- [LaVague](https://github.com/lavague-ai/LaVague) — Large Action Model Web Agent

## Research Papers

- [A Survey on Large Language Model-based Autonomous Agents](https://arxiv.org/abs/2308.11432) — Comprehensive survey
- [The Rise and Potential of LLM-based Agents](https://arxiv.org/abs/2309.07864) — Agent taxonomy
- [Voyager](https://arxiv.org/abs/2305.16291) — Lifelong learning agent in Minecraft
- [Generative Agents](https://arxiv.org/abs/2304.03442) — Interactive simulacra of human behavior
- [ToolLLM](https://arxiv.org/abs/2307.16789) — LLMs learning to use 16,000+ APIs

## Tools & Infrastructure

- [LangSmith](https://smith.langchain.com) — LLM application monitoring and debugging
- [Weights & Biases](https://wandb.ai) — ML experiment tracking (works for agents)
- [Helicone](https://github.com/Helicone/helicone) — Open-source LLM observability
- [Instructor](https://github.com/jxnl/instructor) — Structured outputs from LLMs
