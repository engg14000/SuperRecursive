# Awesome AI Dev Tools [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Curated list of AI-powered development tools, IDE plugins, and coding assistants.

## IDE-Integrated

### Code Completion
- [GitHub Copilot](https://github.com/features/copilot) — AI pair programmer in VS Code, JetBrains, Vim
- [Cursor](https://cursor.sh) — AI-first IDE built on VS Code
- [Windsurf](https://codeium.com/windsurf) — AI-powered IDE by Codeium
- [Codeium](https://codeium.com) — Free AI code completion
- [Tabnine](https://tabnine.com) — AI assistant trained on your code
- [Amazon Q Developer](https://aws.amazon.com/q/developer/) — AWS's AI coding assistant
- [Supermaven](https://supermaven.com) — Fast code completion with large context

### AI Chat in IDE
- [Continue](https://github.com/continuedev/continue) — Open-source AI code assistant for VS Code/JetBrains
- [Cline](https://github.com/cline/cline) — AI agent in VS Code
- [Aider](https://github.com/paul-gauthier/aider) — Terminal-based AI pair programming

## Terminal / CLI

- [Claude Code](https://docs.anthropic.com/claude/docs/claude-code) — Anthropic's agentic coding tool
- [Warp](https://warp.dev) — AI-powered terminal
- [Fig](https://fig.io) — AI-powered autocomplete for terminal (now part of AWS)
- [Shell GPT](https://github.com/TheR1D/shell_gpt) — ChatGPT in your terminal

## Code Review

- [CodeRabbit](https://coderabbit.ai) — AI-powered code review bot for GitHub PRs
- [Codacy](https://codacy.com) — Automated code review with AI analysis
- [Sourcery](https://sourcery.ai) — AI-powered Python code reviewer

## Documentation

- [Mintlify](https://mintlify.com) — AI-powered documentation generator
- [Readme.so](https://readme.so) — README generator with AI assistance
- [Docstring AI](https://github.com/MichaelisTr662/DocstringAI) — Auto-generate docstrings

## Testing

- [Codium AI](https://www.codium.ai/) — AI-generated test suites
- [Diffblue Cover](https://diffblue.com) — Autonomous Java unit test generation
- [Mabl](https://mabl.com) — Intelligent test automation

## Design to Code

- [v0](https://v0.dev) — Vercel's AI UI generator
- [Builder.io](https://builder.io) — Visual development platform with AI
- [Locofy](https://locofy.ai) — Turn Figma designs into code
- [Screenshot to Code](https://github.com/abi/screenshot-to-code) — Convert screenshots to HTML/CSS
