# ?? Vibe Coding

> The world's first systematic approach to mood-based prompt engineering. Match your AI's interaction style to your mental state for maximum productivity and flow.

## ?? The Philosophy

Developer productivity isn't just about tools - it's about **mental state**. A developer in a creative flow shouldn't receive dry, structured responses. A developer debugging under pressure needs precision, not poetry.

Vibe Coding adapts AI prompts to match your current mood:

| Vibe | When You Feel | AI Becomes | Best For |
|------|--------------|------------|----------|
| ?? **Zen** | Focused, calm, methodical | Patient, minimal, step-by-step | Deep work, refactoring |
| ?? **Debug** | Analytical, hunting | Forensic, systematic, thorough | Bug hunting, root cause |
| ?? **Creative** | Inspired, exploratory | Expansive, playful, experimental | Ideation, prototyping |
| ?? **Refactor** | Disciplined, cleaning | Clean, pattern-focused, principled | Code improvement |
| ? **Sprint** | Urgent, ship-it | Fast, pragmatic, minimal ceremony | Deadlines, MVPs |

## ?? Quick Start

1. Pick your current vibe from the table above
2. Open the corresponding file in `moods/`
3. Copy the prompt to your AI tool's configuration
4. Code in harmony with your mental state
