# Copilot Instructions

## General Instructions

*   **Brevity**: Keep responses concise and to the point.
*   **Context**: Use the surrounding code as context.
*   **Standards**: Follow existing coding styles and conventions.
*   **Comments**: Add meaningful comments where necessary.

## Language Specifics

### Python
*   Use type hints.
*   Follow PEP 8.
*   Use docstrings for classes and methods.

### JavaScript/TypeScript
*   Use `const` and `let` appropriately.
*   Prefer functional programming paradigms.
*   Use JSDoc for complex functions.

## Testing
*   Suggest tests for any new functionality.
*   Ensure existing tests pass.
