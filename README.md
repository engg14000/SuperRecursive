## Repository Structure

The repository is organized by tool/platform. Inside each tool's directory, you will find:

*   `system-prompts/`: Specific instructions for the AI model/agent.
*   `context-templates/`: Templates for structuring context to get the best results.
*   `internal-tools/`: Helper scripts or configurations specific to the tool.
*   `models/`: Model cards or configuration files.

## Goals

1.  **Centralize Knowledge**: A single source of truth for optimal prompting strategies across different AI engineering tools.
2.  **Facilitate Recursion**: Enable AI agents to use this repository to improve their own performance or the performance of other agents.
3.  **Community Driven**: Open for contributions to keep up with the rapidly evolving AI landscape.
