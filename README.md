```bash

cd SuperRecursive
```


## 🛠️ System Prompts — AI Tool Coverage

> **30+ AI coding tools** with tailored system prompts, context templates, and internal tool configurations. Each tool folder follows a consistent structure for easy navigation.

### Tool Directory Structure

Every tool folder contains:
```
tool-name/
├── README.md              # Tool overview, capabilities, tips
├── system-prompts/        # Role-based system prompts
│   ├── default.md         # General-purpose prompt
│   ├── architect.md       # Architecture-focused
│   ├── debugger.md        # Debug-focused
│   └── recursive.md       # Self-improving variant
├── context-templates/     # Structured context formats
│   ├── project-context.md # Project-level context
│   ├── bug-report.md      # Bug investigation context
│   └── feature-spec.md    # Feature specification context
└── internal-tools/        # Tool-specific configs
    ├── config.yaml        # Configuration file
    └── rules.md           # Custom rules/instructions
```

## 🎨 Vibe Coding

> **The world's first systematic approach to mood-based prompt engineering.** Match your prompts to your mental state for maximum productivity and flow.

### What is Vibe Coding?

Vibe Coding recognizes that **developer productivity is tied to mental state**. Different moods call for different AI interaction styles:

- 🧘 **Zen Mode**: Calm, methodical, minimal. For focused deep work.
- 🐛 **Debug Flow**: Analytical, systematic, forensic. For hunting bugs.
- 🎨 **Creative Mode**: Expansive, experimental, playful. For ideation.
- 🔧 **Refactor Flow**: Clean, disciplined, pattern-focused. For code improvement.
- ⚡ **Sprint Mode**: Fast, pragmatic, ship-it. For deadlines.
