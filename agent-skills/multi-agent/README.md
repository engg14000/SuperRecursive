## When to Use Multi-Agent

```
Single Agent:                    Multi-Agent:
- Simple tasks                   - Complex projects
- Clear requirements              - Multiple specializations needed
- < 1 hour of work               - > 1 hour of work
- Single domain                   - Cross-domain (code + docs + tests)
```
