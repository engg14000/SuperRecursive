## 30-Second Setup

```bash
# Clone the starter kit
git clone https://github.com/engg14000/SuperRecursive.git
cd SuperRecursive/starter-kit

# Copy config for your tool
cp cursor-setup/.cursorrules /path/to/your/project/.cursorrules
# OR
cp claude-code-setup/CLAUDE.md /path/to/your/project/CLAUDE.md
# OR
cp copilot-setup/.github/copilot-instructions.md /path/to/your/project/.github/

# Customize for your project
# Edit the config files to match your tech stack and conventions
```
